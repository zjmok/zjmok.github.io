# Kotlin 集合 流 中的操作符

跟 RxJava 和 Java8 中一样，Kotlin 也有类似的操作符

## 集合Collection 流Flow 的操作符

Kotlin 的集合（Collection）和流（Flow）提供了丰富的操作符来处理数据

| :----------- | :--------------- | :------- | :----------------------------------------------------------------------- | :------------------------------------------------------------------------- |

|              | `mapNotNull`     | 集合     | 对每个非null元素进行转换，并过滤掉null                                     |                                                                          |
|              | `mapIndexed`     | 集合     | 带索引的map操作                                                          |                                                                          |
|              | `flatMap`        | 集合/流  | 将每个元素转换为一个集合或流，然后将所有这些集合或流“扁平化”为一个单一的集合或流 | `listOf(1,2).flatMap { listOf(it, it+1) }` 得到 `[1,2,2,3]`  |

|              | `takeWhile`      | 集合     | 取满足条件的元素，直到遇到第一个不满足条件的元素                               |                                                                          |
|              | `distinct`       | 集合     | 去除重复元素                                                              |                                                                          |

### 使用建议

1.  **集合 (Collections)**: 主要用于处理**有限、已在内存中的数据**。操作通常是**急求值（eager evaluation）** 的，即立即执行并返回结果。
2.  **序列 (Sequences)**: 用于对集合进行**惰性（lazy evaluation）** 处理，避免创建中间集合，适合处理大量数据或链式操作。许多集合操作符也适用于序列。
3.  **流 (Flow)**: 主要用于**异步数据流**处理，支持协程和背压处理。操作符设计为**冷流（cold stream）** 且默认是顺序的。Flow 可以切换执行的线程上下文。

### 性能提示

*   对大型集合进行复杂操作链时（多个 `map`、`filter` 等），考虑使用 `asSequence()` 转换为序列以避免创建中间集合，处理完毕后再用 `toList()` 转回集合。
*   Flow 的 `flatMapMerge` 可以设置并发数，平衡资源使用和效率。
*   使用 Flow 时，根据需求选择合适的 `flatMap` 变体 (`Concat`, `Merge`, `Latest`) 。
