## fvm 4.x.x 使用 fvm fork 添加 fork 版本

4.0.0-bete.1 是第一个 4.x.x 版本，支持新功能使用命令添加 fork 版本

这个版本只是 fork 的官方版，不是修改版。例如在 github 下载慢，可以到 gitlab 上 mirror 一个 flutter 仓库，算是 fork 的原版

如果添加修改版，可能会在 list 与原版冲突。测试了 harmony 的 flutter 版本，版本号不兼容不能直接用，只能用 dev 这样的渠道

```
# 添加 fork 仓库的别名 gitlab
fvm fork add gitlab https://gitlab.com/zjmok/flutter.git

# 安装
fvm install gitlab/dev

# 使用
fvm use gitlab/dev

# 执行完上面步骤就能使用 fvm list 看到新加的版本了
fvm list
```

`fvm fork list` 是查看 fork 的列表，不是查看 fork 的 flutter 版本的列表

## 直接更换默认仓库 URL 为 fork 版本的 URL

```
fvm config --flutter-url https://gitlab.com/zjmok/flutter.git
```

## 添加修改版，如适配 HarmonyOS 的 Flutter 版本，需要使用前缀 `custom_` 的方式

手动将第三方仓库放到 cache 目录，并用仓库名称前缀 `custom_` 才能在 fvm 把这个版本管理起来

HarmonyOS 的 Flutter 版本，已经从 gitee 迁移到了 gitcode

```
cd ~/.fvm/versions

git clone https://gitcode.com/openharmony-tpc/flutter_flutter.git custom_harmony
```

克隆下来，手动切换到目标分支目标节点
