## Flutter

### 环境与版本管理
- `flutter doctor`：检查开发环境配置（Android/iOS/Xcode 等）
- `flutter --version`：查看当前 Flutter 和 Dart 版本
- `flutter upgrade`：升级 Flutter SDK 到最新版本
- `flutter channel`：查看或切换渠道（如 stable、beta、dev）

---

### 项目创建与依赖管理
- `flutter create <项目名>`：创建新项目
- `flutter pub get`：安装项目依赖
- `flutter pub upgrade`：升级依赖到最新兼容版本
- `flutter pub outdated` ：列出所有依赖项的当前版本、可升级版本、可解析版本和最新版本
- `flutter pub add <包名>`：添加新依赖（自动更新 `pubspec.yaml`）

可升级版本（Upgradable）：可以直接升级的版本（不改 pubspec.yaml）  
可解析版本（Resolvable）：修改 pubspec.yaml 后可解析的版本  

---

### 运行与调试
- `flutter run`：运行项目（默认 Debug 模式）
- `flutter run --release`：以发布模式运行
- `flutter attach`：连接到正在运行的 Flutter 应用（用于原生嵌入调试）
- `flutter logs`：查看运行日志
- `flutter screenshot`：截取设备屏幕

```

# 运行指定项目 main
flutter run lib/main.dart

# 指定设备
flutter devices # 列出已连接设备
flutter run -d edge
flutter run -d chrome
flutter run -d windows
```

---

### 构建与打包
- `flutter build apk`：构建 Android APK
- `flutter build ios`：构建 iOS 应用（需 macOS）
- `flutter build web`：构建 Web 应用
- `flutter build windows/macos/linux`：构建桌面应用

---

### 清理与格式化
- `flutter clean`：清除构建缓存
- `flutter format .`：格式化当前目录下的 Dart 代码

---

### 代码分析与测试
- `flutter analyze`：静态代码分析
- `flutter test`：运行单元测试

---

### 设备与模拟器管理
- `flutter devices`：列出已连接设备
- `flutter emulators`：列出或启动模拟器

---

## Flutter OH

<https://gitcode.com/openharmony-tpc/flutter_flutter#构建步骤>

```
# 创建工程
flutter create --platforms ohos <projectName>

# 进入工程根目录编译
# 示例：flutter build hap [--target-platform ohos-arm64] [--local-engine=<DIR>/src/out/ohos_release_arm64] --release
flutter build hap --target-platform ohos-arm64 --<debug|release|profile> [--local-engine=src/out/<engine产物目录> --local-engine-host=src/out/<engine host目录>/]
```

设备
```
flutter devices
```

运行
```
flutter run --debug [--local-engine=<DIR>/src/out/ohos_debug_unopt_arm64] [--local-engine-host=<DIR>/src/out/host_debug_unopt] -d <device-id>
```

构建
```
# 示例：flutter build app --release [--local-engine=<DIR>/src/out/ohos_release_arm64] [--local-engine-host=<DIR>/src/out/host_release]
flutter build app --release
```

也可用 hdc 安装
```
hdc -t <deviceId> install <hap file path>
```
