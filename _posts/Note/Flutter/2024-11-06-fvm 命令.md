# fvm

```batch
>fvm -h
Flutter Version Management: A cli to manage Flutter SDK versions.

Usage: fvm <command> [arguments]

Global options:
-h, --help       Print this usage information.
    --verbose    Print verbose output.
-v, --version    Print the current version.

Available commands:
  api        JSON API for FVM data
  config     Set global configuration settings for FVM
  dart       Proxies Dart Commands
  destroy    Destroy FVM cache by deleting FVM directory
  doctor     Shows information about environment, and project configuration.
  exec       Executes scripts with the configured Flutter SDK
  flavor     Executes a Flutter command using a specified version defined by the project flavor
  flutter    Proxies Flutter Commands
  global     Sets Flutter SDK Version as a global
  install    Installs Flutter SDK Version
  list       Lists installed Flutter SDK Versions
  releases   View all Flutter SDK releases available for install.
  remove     Removes Flutter SDK Version
  spawn      Spawns a command on a Flutter version
  use        Sets Flutter SDK Version you would like to use in a project

Run "fvm help <command>" for more information about a command.
```

## 常用管理版本命令

- `fvm list` 查看已安装版本
- `fvm releases` 查看所以可用版本
- `fvm use <版本号>` 使用指定版本
- `fvm use --path <本地路径的flutter仓库>` 会使用软连接，但 `fvm list` 不会显示
- `fvm install <版本号>` 安装指定版本
- `fvm install --git <git远程地址>` 安装指定版本

```batch
fvm install --git https://github.com/your-org/flutter.git --branch your-feature-branch
fvm install --git https://github.com/your-org/flutter.git --tag v3.22.0-custom
```

切换分支和管理 git 仓库，可直接进入目录使用 git 操作

## 添加第三方 Flutter 版本

### 4.x.x 版本的 fvm fork

```batch
>fvm fork -h
Manage Flutter fork aliases

Usage: fvm fork
-h, --help    Print this usage information.

Available subcommands:
  add      Adds a new Flutter fork alias for custom repositories
  list     Lists all configured Flutter fork aliases
  remove   Removes a configured Flutter fork alias

Run "fvm help" to see global options.
```

增加管理一个 fork

- `fvm fork add <name> <url>` 使用 fork 版本的 flutter（需要 fvm 4.x.x 版本）

```batch
# 提示：国内镜像不要代理
fvm fork add harmony https://gitcode.com/openharmony-tpc/flutter_flutter.git
fvm install harmony/dev
```

`fvm use harmony/dev` 之后使用 `fvm fork list` 就能看到这个仓库了

### 把 `custom_` 前缀的仓库，放到 cache 目录

```batch
cd Z:\.home\.fvm\versions\
git clone -b dev --single-branch https://gitcode.com/openharmony-tpc/flutter_flutter.git custom_harmony
```

之后使用 `fvm list` 就能看到这个仓库了

---

`.fvm/cache.git` 尽量不要手动操作此目录，由 fvm 自动管理。
可能会影响 `fvm list` 或 `fvm use` 的一致性，
下次运行 `fvm install` 或 `fvm upgrade` 时可能会覆盖改动
