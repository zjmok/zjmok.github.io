# Kuikly 组件

- View 容器，是个 Flex 容器，使用 Flexbox 布局，View 不设置宽高则大小为包裹内容

- Text 文本

  - RichText 富文本

  - Input 单行输入框

    - TextArea 多行输入框

- Image 图片

- Canvas 自绘画布

- Button 按钮

- Scroller 滚动容器

  - List 列表，List 必须设置宽高

    - WaterFallList 瀑布流

- SliderPage 轮播图，必须设置 item 宽高

- PageList 分页列表，List 必须设置宽高

- Tabs 标签栏，与 PageList 配套使用

- Refresh 下拉刷新组件

- FooterRefresh 列表尾部刷新

- DatePicker 日期选择器

- ScrollPicker 滚动选择器，自定义

- Slider 滑动器，类似 Android 的 SeekBar

- Switch 开关

- Blur 高斯模糊组件，毛玻璃效果

- ActivityIndicator 活动指示器，旋转菊花，loading

- Hover 悬停置顶，列表粘性头置顶效果

- Mask 遮罩，使用一张图片的遮罩轮廓显示另一张图片

- CheckBox 复选框

- PAG 动画播放组件，类Lottie播放动画的组件

- APNG 动画播放组件，播放APNG图片动画的组件

- Modal 模态，窗口组件

- AlertDialog 提示对话框，iOS 风格

- ActionSheet 操作表，类似 BottomSheet，取消 + 单选列表

- Video 播放器
