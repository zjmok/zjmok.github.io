## 组件引用 ViewRef

```kotlin
@Page("HelloWorldPage")
internal class HelloWorldPage : Pager() {
    
    lateinit var listViewRef: ViewRef<ListView<*, *>> // 1.声明ListView类型的ViewRef变量

    override fun body(): ViewBuilder {
        val ctx = this
        return {
            attr {
                backgroundColor(Color.WHITE)
            }
            
            event { 
                click { 
                    // 3.点击的时候, 调用List组件内的setContentOffset方法
                    ctx.listViewRef.view?.setContentOffset(0f, 100f)
                }
            }

            List { 
                ref { 
                    ctx.listViewRef = it // 2.在ref{}闭包内初始化ViewRef
                }
                attr { 
                    flex(1f)
                }
            }
        }
    }

```

## ComposeView 生命周期

1. `created` 已经创建
2. `viewWillLoad` view 即将加载，在 body 前调用
3. `viewDidLoad` view 已经加载，在 body 后调用
4. `viewDidLayout` view 已经测量完毕
5. `viewWillUnload` view 即将移除
6. `viewDidUnload` view 已经移除
7. `viewDestroyed` view 已经销毁

## Module，调用 Native API

获取方式，在 Pager 或 ComposeView 的 created 后执行，或其它地方通过 Pager 对象获取 `PagerManager.getCurrentPager()`

- `acquireModule` 返回 module 或报错

- `getModule` 返回 module 或 null

Module 类型

- `NotifyModule` 通知模块

- `MemoryCacheModule` 内存缓存模块

- `SharedPreferencesModule` 键值对磁盘缓存模块

---

最终与 Native 通信的是 `Module` 类的 `toNative` 方法

## RouterModule，页面跳转

- `RouterModule.openPage` 打开 Pager

- `RouterModule.closePage` 关闭 Pager

## NotifyModule，在 Kuikly 和 Native 互发通知

`NotifyModule` 使用 `Module.toNative` 实现双向通知

- `postNotify` 用于发送
- `addNotify` 用于接收
- `removeNotify` 用于移除接收监听

### Kuikly

发送

- `notifyModule.postNotify(key, JSONObject().apply { put() }` 发送通知

接收

- `val eventCallbackRef = notifyModule.addNotify(key){}` 接收通知

- `notifyModule.removeNotify(key, eventCallbackRef)` 在页面销毁时 `pageWillDestroy` 移除通知

接收

android

```kotlin
val kuiklyReceiver = object : BroadcastReceiver() {
    override fun onReceive(context: Context, intent: Intent) {
        val eventName = intent.getKuiklyEventName() // 接收到的事件名字
        val data = intent.getKuiklyEventParams() // kuikly侧传递的参数
    }
}

// 注册
context.registerKuiklyBroadcastReceiver(kuiklyReceiver)

// 解注册
context.unregisterKuiklyBroadcastReceiver(kuiklyReceiver)
```

ios

```objc
[[NSNotificationCenter defaultCenter] addObserver:self selector:@selector(onReceiveNotication:) name:@"test" object:nil];

- (void)onReceiveNotication:(NSNotification *)notification {

    NSDictionary *userInfo = notification.userInfo; // Kuikly侧传递的参数
}

// 记得解注册
```
