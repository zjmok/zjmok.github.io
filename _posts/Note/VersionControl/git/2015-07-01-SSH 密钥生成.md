生成 SSH 密钥过程：

- 1.查看是否已经有了 SSH 密钥：`cd ~/.ssh`

如果没有密钥则不会有此文件夹，有则备份删除

- 2.生存密钥：

```
ssh-keygen -t rsa -C mzx0766@gmail.com
```

按提示输入保持路径，默认目录在 `~/.ssh/`  
按提示输入密码，默认空  
按提示确认密码  

最后得到了两个文件：私钥 `id_rsa` 和公钥 `id_rsa.pub`

- 3.添加私钥到 ssh-agent（客户端）：
```
ssh-add ~/.ssh/id_rsa
```

需要输入之前的密码。

- 4.在 SSH 服务端添加 SSH 公钥，`id_rsa.pub` 里面的内容就是公钥。

**`ssh-keygen` 核心参数说明**

| 参数 | 作用 | 示例/注意事项 |
|------|------|--------------|
| `-t` | 指定密钥类型 | `rsa`/`ed25519`/`ecdsa` |
| `-C` | 添加注释（通常用邮箱） | `-C "your_email@example.com"` |
| `-b` | 密钥位数（RSA默认3072） | `-b 4096`（增强安全性） |
| `-f` | 指定密钥文件路径 | `-f ~/.ssh/my_custom_key` |
| `-N` | 设置密钥密码 | `-N "my_passphrase"` |
| `-q` | 静默模式 | 不显示进度信息 |
| `-P` | 直接指定密码 | `-P "old_passphrase"`（用于修改密码） |

示例

```
ssh-keygen \
  -t rsa \
  -b 4096 \
  -C "deploy@server" \
  -f ~/.ssh/new_folder/new_name \
  -N "password"
```
