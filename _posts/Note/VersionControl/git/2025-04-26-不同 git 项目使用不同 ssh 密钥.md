# 不同 git 项目使用不同 ssh 密钥

## git 配置直接指定密钥（推荐）

```shell
# 在工作项目中执行
git config core.sshCommand "ssh -i ~/.ssh/work_github"

# 在个人项目中执行
git config core.sshCommand "ssh -i ~/.ssh/personal_github"
```

在 `.git/config` 文件中对应的格式是

```ini
[core]
	sshCommand = ssh -i ~/.ssh/personal_github
```

## 使用 SSH Config 配置，使用指定的密钥

配置 `~/.ssh/config`

```config
# 工作账号配置
Host github.com-work
  HostName github.com
  User git
  IdentityFile ~/.ssh/work_github
  IdentitiesOnly yes

# 个人账号配置
Host github.com-personal
  HostName github.com
  User git
  IdentityFile ~/.ssh/personal_github
  IdentitiesOnly yes
```

修改 git 远程地址

```shell
# 进入工作项目目录
git remote set-url origin git@github.com-work:company/project.git

# 进入个人项目目录
git remote set-url origin git@github.com-personal:username/repo.git
```

## 使用 -c 参数可以临时指定配置项

```shell
git -c core.sshCommand "ssh -i ~/.ssh/personal_github" <git操作>
```
