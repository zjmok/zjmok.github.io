## 常用的 git 命令

- 浅克隆

`git clone --branch 分支 git地址 --depth 提交深度(最新的一层)`

```
git clone --branch nougat-mr2.3-release https://github.com/aosp-mirror/platform_frameworks_base.git --depth 1
```

## 修改 git 配置

增加或修改 user 的 name 和 email：

```
git config --global user.name "harry"
git config --global user.email "harry@xxx.com"
```

对应 `~/.gitconfig` 文件内容

```
[user]
	name = harry
	email = harry@xxx.com
```

不加 `--global` 就是只对项目生效，对应文件 `.git/config`

其它配置也一样，例如 core 的 filemode

```
git config --global core.filemode false
```

```
[core]
	filemode = false
```

## git 基础命令

- 添加一个远程仓库

```
# 增加
git remote add origin url0
git remote add second url1

# 修改
git remote set-url origin url0
git remote set-url second url1
```

对应 `.git/config` 文件内容

```
[remote "origin"]
        url = url0
        fetch = +refs/heads/*:refs/remotes/origin/*
[remote "second"]
        url = url1
        fetch = +refs/heads/*:refs/remotes/origin/*
[branch "master"]
        remote = origin
        remote = second
```

- pull 操作

使用以下命令，可以分别从两个远程仓库pull：

```
git pull origin master
git pull second master
```

- push 操作

使用以下命令，可以分别push到两个远程仓库：

```
git push origin master
git push second master
```

- 更多

**操作工作区文件**

| 命令 | 作用 |
|------|------|
| `git add <file>` | 将工作区文件添加到暂存区 |
| `git restore <file>` | 丢弃工作区文件的修改（Git 2.23+） |
| `git checkout -- <file>` | 丢弃工作区修改（旧版 Git） |
| `git rm <file>` | 删除工作区文件并暂存删除操作 |
| `git clean -fd` | 删除所有未跟踪的文件和目录（危险！） |

```
# 取消文件的暂存
git restore --staged <file-path>
# 等同上面，--mixed 是默认值，可以不加
git reset --mixed <file>

# 取消所有文件的暂存
git restore --staged .
git reset HEAD

# 添加所有 md 文件
git add '**/*.md'

```


## 贮藏 stash

贮藏未提交的更改
```
git stash
```

查看stash栈列表
```
git stash list
```

应用最近一个stash版本并且移除
```
git stash pop
```

清空stash list
```
git stash clear
```

应用某个stash版本
```
git stash apply stash@{0}
```

## 摘樱桃 cherry-pick

合并其它分支上的某些提交到当前分支(git cherry-pick [hashValue,hashValue1]), 支持多个哈希值一起哦。
```
git cherry-pick y8vawv iuerg9va 9vu38av vb9u3gv
```
