# Harmony 使用三方库

在 IDE 目录 `DevEco Studio 5.0.3.0\tools\ohpm\bin\` 这个 bin 目录下有 `ohpm` 可执行文件

可以配置到环境变量，或者直接在 IDE 里 `Alt`+`F12` 打开命令窗口使用

可以先测试是否可用

```
ohpm ls
```

列出已安装的库

### 安装三方库并在项目中使用

1. 查找需要的三方库

地址 https://ohpm.openharmony.cn/

2. 安装三方库

使用 `ohpm install xxx` 或 `ohpm i xxx`

```
ohpm install @ohos/axios
```

或 在根目录 `oh-package.json5` 的 `dependencies` 配置后 sync，也会自动 install

```
{
  "modelVersion": "5.0.0",
  "description": "Please describe the basic information.",
  "dependencies": {
    "@ohos/axios": "^2.2.4"
  },
  "devDependencies": {
    "@ohos/hypium": "1.0.19",
    "@ohos/hamock": "1.0.0"
  },
  "dynamicDependencies": {}
}
```

3. 在项目中 module 配置

打开 `entry/oh-package.json5`，在 `dependencies` 中配置安装好的库

```
{
  "name": "entry",
  "version": "1.0.0",
  "description": "Please describe the basic information.",
  "main": "",
  "author": "",
  "license": "",
  "dependencies": {
    "@ohos/axios": "2.2.4"
  }
}

```

4. 最后就可用在项目中使用了

```
Button("test axios")
  .onClick(() => {
    axios.request({
      method: "get",
      url: "https://ohpm.openharmony.cn/"
    }).then((response: AxiosResponse) => {
      console.info('result:' + JSON.stringify(response.data));
    }).catch((error: AxiosError) => {
      console.error(error.message);
    })
  })
```

### Others

`oh-package-lock.json5` 文件是 `npm` 包管理器用于记录项目依赖的具体版本号，以确保其他开发者在相同代码基础上使用相同版本的依赖，从而保证项目环境的一致性

git 不用忽略，也不用手动改，直接 add 和 commit
