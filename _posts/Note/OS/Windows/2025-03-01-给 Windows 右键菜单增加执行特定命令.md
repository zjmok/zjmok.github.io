# 给 Windows 右键菜单增加执行特定命令

- `[HKEY_CLASSES_ROOT\*\shell\自定义项]`，文件右击，获取目标 `%1`
- `[HKEY_CLASSES_ROOT\Directory\shell\自定义项]`，目录右击，获取目标 `%1`
- `[HKEY_CLASSES_ROOT\AllFilesystemObjects\shell\自定义项]`，文件和目录右击，获取目标 `%1`

- `[HKEY_CLASSES_ROOT\Directory\Background\shell\自定义项]`，目录空白处右击，在当前目录执行，当前目录 `%V`

数值数据：右击显示的名称

再在下面加个项 `command`，就可以设置执行命令

## 右键文件，执行命令

例子

```ini
[HKEY_CLASSES_ROOT\*\shell\SHA256]
@="校验 SHA256"
"Icon"="imageres.dll,-5323"

[HKEY_CLASSES_ROOT\*\shell\SHA256\command]
@="cmd /c CertUtil -hashfile \"%1\" SHA256 & pause"
```

`%1` 可以获取右击的目标。文件夹右击，同

## 右键文件夹背景空白处，执行命令

例子

```ini
[HKEY_CLASSES_ROOT\Directory\Background\shell\OpenWSL]
@="打开 Ubuntu_20.04_LTS_1"
"Icon"="%SystemRoot%\\System32\\wsl.exe"

[HKEY_CLASSES_ROOT\Directory\Background\shell\OpenWSL\command]
@="cmd /s /k pushd \"%V\" && wsl -d Ubuntu_20.04_LTS_1"
```

`%V` 可以获取当前目录

## 右击文件或文件夹，执行命令，调用脚本

例子

```ini
Windows Registry Editor Version 5.00

[HKEY_CLASSES_ROOT\AllFilesystemObjects\shell\SymlinkTo]
@="创建软连接到..."

[HKEY_CLASSES_ROOT\AllFilesystemObjects\shell\SymlinkTo\command]
@="powershell.exe -ExecutionPolicy Bypass -File \"..\\ps1\\SymlinkTo.ps1\" \"%1\""
```

```powershell
param (
    [string]$sourcePath
)

Add-Type -AssemblyName System.Windows.Forms

# 获取名称（文件或文件夹）
$targetName = [System.IO.Path]::GetFileName($sourcePath)

# 弹出目标文件夹选择框
$dialog = New-Object System.Windows.Forms.FolderBrowserDialog
$dialog.Description = "选择软连接的保存目录"
if ($dialog.ShowDialog() -ne "OK") { exit }

$targetDir  = $dialog.SelectedPath

$symlinkPath = Join-Path $targetDir $targetName

# 创建软连接
# 判断类型（文件/目录）
if (Test-Path $sourcePath -PathType Container) {
    cmd /c mklink /D "`"$symlinkPath`"" "`"$sourcePath`""
} else {
    cmd /c mklink "`"$symlinkPath`"" "`"$sourcePath`""
}

# 成功提示
[System.Windows.Forms.MessageBox]::Show("软连接已创建: $symlinkPath", "完成", 0)
```
